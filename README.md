# 도토리 베이커리 (Acorn Bakery)

동물 친구들이 사는 마을에서 작은 빵집을 여는 2D 가게 운영 게임이에요. Godot 4로 만들어요.

지금은 **두 번째 버전**이에요. 가게 홀, 주방, 도토리 숲 마을 세 곳이 있고, 배경음악과 효과음이 나와요.

## 집 컴퓨터에서 실행하기

1. [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/) 표준판(Standard)을 받아요. 설치 없이 압축만 풀면 돼요.
2. 이 저장소를 받아요.
   ```
   git clone https://github.com/ryuthwjd12-ctrl/bakery-game.git
   ```
3. Godot를 열고 **가져오기(Import)** 에서 `bakery-game/project.godot` 를 골라요.
4. 처음 열 때 그림을 불러오느라 조금 걸려요. 끝나면 오른쪽 위 ▶ 버튼(F5)으로 실행해요.

## 조작

| 키 | 하는 일 |
|---|---|
| 방향키 / WASD, 또는 바닥 클릭 | 걷기 |
| 손님·탁자 클릭 | 걸어가서 주문 받기, 음식 내주기, 치우기 |
| E (또는 스페이스) | 주문 받기, 음식 내주기, 치우기, 가게 열기, 산딸기 따기, 주민에게 인사 |
| R | 레시피북 |
| I | 가방 (체력·마나, 무기 바꾸기, 모은 재료) |
| M | 세계 지도 |
| 스페이스 / 오른쪽 클릭 (숲에서) | 공격 (장착한 무기에 따라 휘두르기 또는 마법) |
| Esc | 창 닫기, 일시정지 메뉴(저장·불러오기·설정·처음 화면) |

## 지금 들어 있는 것

- **시작 화면**: 이어하기, 새 게임(여자/남자 주인공 고르기), 설정, 끝내기.
- **가게 홀**: 처음엔 알바생이 없어서 주인공이 혼자 주문 받고, 만들고, 내주고, 치워요.
  - 동물 손님(토끼·고양이·사슴·곰·병아리·다람쥐)이 걸어 들어와 의자에 앉아요. 사람은 주인공 혼자예요.
  - 손님은 말 대신 생각 풍선 그림으로 주문해요. 처음엔 "!"만 떠 있고, 주문을 받아야 원하는 음식 그림이 나와요.
  - 받은 주문은 화면 위에 손님 얼굴과 음식, 기다림 바로 줄 서요. 받은 순서대로만 내줄 수 있어요.
  - 손님 풍선 옆 얼굴로 기분이 보여요(웃음 → 무표정 → 찡그림). 먹을 때는 음식이 조금씩 줄고, 다 먹으면 하트가 떠요.
  - 기다림 바가 다 줄면 손님이 화나서 돌아가요. 떠난 자리는 치워야 다음 손님이 앉아요.
  - 가구는 가게 그림에 그려진 그대로이고, 손님은 그림 속 의자에 앉아요. 바닥을 누르면 가구를 돌아서 걸어가요.
- **주방**: 그릇장(그릇·도구), 냉장고(버터·달걀·우유·생크림), 냉동고(산딸기), 찬장(밀가루·설탕·초콜릿)을 눌러 재료를 골라요.
  - 고른 재료는 아래 다섯 칸으로 날아가요. 순서는 상관없어요.
  - 처음 아는 레시피 3개(버터 쿠키, 따뜻한 우유, 우유 식빵)는 빈 칸에 재료 그림자가 희미하게 보여요.
  - 틀리면 재료만 잃어요. 맞으면 오븐에서 구워져 진열대에 놓여요.
- **도토리 숲 마을**: 카메라가 주인공을 따라가요. 동물 주민이 길을 오가고, 가게로 가는 손님도 보여요. 빵집 문 앞으로 걸어가면 다시 들어가요.
  - 재료 가게에서 재료를 사고, 덤불에서 산딸기를 하루 한 번 따요.
  - 가게 레벨 2가 되면 마을의 강아지를 알바생으로 고용할 수 있어요(150골드).
- **가게 레벨**: 손님을 만족시키면 평판이 오르고, 레벨이 오르면 메뉴가 늘어요.
- **넓은 가게**: 홀은 카메라가 주인공을 따라가요. 안쪽 오른쪽 문 너머에 별관이 있고, 가구점에서 산 탁자 세트(최대 4개)가 놓여요.
- **가구점·특산물 가게·재료 가게·무기 상점**: 모든 가게에서 그 가게 물건을 사고팔아요. 되팔 때는 산 값의 30%예요.
- **부탁 손님**: 둘째 날부터 하루 한 번쯤 ★ 손님이 와요. 사연을 듣고 스페셜 요리를 만들어 주면 큰 사례를 받아요.
- **모험**: 마을 가장자리 길로 나가면 숲길(북·동·남·서)이고, 숲 끝에 꽃잎 언덕·조개 해변·사과 과수원·눈꽃 마을이 있어요.
  - 숲에는 몬스터 6종(슬라임, 버섯, 다람쥐, 꿀벌, 양, 아기 용)이 있고, 쓰러뜨리면 골드와 재료를 줘요.
  - 공격은 장착한 무기가 정해요. 근접 무기는 앞을 휘두르고, 마법 무기는 반짝이를 쏘며 마나를 써요. 비싼 무기일수록 세요. 캐릭터 스킬은 없어요.
  - 체력이 0이 되면 골드 10%를 잃고 가게에서 깨요. 자고 나면 체력·마나가 다 차요.
  - 눈꽃 마을 광장에는 눈사람 거인 보스가 있어요. 이기면 눈꽃 쿠키 레시피를 줘요.
  - 다른 마을에는 그 마을 상점이 있어요.
- **경영 일지**: 하루가 끝나면 판매 수입, 팁, 재료비, 순수익, 팔린 메뉴, 평판 변화를 보여 줘요.
- **하루**: 오전 9시부터 오후 9시까지(실제 12분), 오후 8시 이후엔 손님이 안 와요. 하루가 끝나면 정산 화면이 나오고 저장돼요.
- **첫 영업 안내**: 첫날 오른쪽 아래에 할 일 네 가지가 보이고, 해내면 체크돼요.
- **설정**: 배경음악·효과음 크기, 전체 화면.

## 폴더

| 폴더 | 내용 |
|---|---|
| `scripts/` | 게임 코드 (GDScript) |
| `assets/` | 게임에 쓰는 그림 (잘라낸 것) |
| `art/raw/` | 제미나이 원본 그림. Godot는 이 폴더를 무시해요 |
| `tools/slice.py` | 원본 그림을 잘라 `assets/` 와 `scripts/sprite_data.gd` 를 만드는 스크립트 |
| `tools/draw_kitchen.py` | 주방 그릇장·냉장고·찬장 그림을 그리는 스크립트 |
| `tools/clean_signs.py` | 마을 간판의 영어 글자를 지우고 그림으로 바꾸는 스크립트 |
| `tools/cut_furniture.py` | 가구 있는 가게 그림과 빈 방 그림의 차이로 탁자·화분을 떼어내는 스크립트 |
| `tools/icons2.py` | 쿠키·재료 아이콘, 몬스터, 주인공 공격 동작, 보스를 잘라내는 스크립트 |
| `tools/make_maps.py` | 숲길·다른 마을·세계 지도 그림을 만드는 스크립트 |
| `tools/clean_backgrounds.py` | 홀 메뉴판 영어 글자와 배경 오른쪽 아래 생성 표시를 지우는 스크립트 |
| `tools/make_audio.py` | 배경음악·효과음을 직접 만드는 스크립트 (`assets/audio/`) |
| `tools/shots.tscn`, `tools/smoke.tscn` | 개발용 화면 찍기·자동 점검 장면 |
| `docs/` | 기획서와 그림 프롬프트 |

## 그림 다시 자르기

새 그림을 `art/raw/` 에 넣고 `tools/slice.py` 의 좌표를 고친 뒤:

```
pip install pillow numpy scipy
python3 tools/slice.py
python3 tools/make_audio.py   # 소리를 다시 만들 때 (ffmpeg 필요)
```
