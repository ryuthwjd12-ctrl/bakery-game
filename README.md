# 도토리 베이커리 (Acorn Bakery)

동물 친구들이 사는 마을에서 작은 빵집을 여는 2D 가게 운영 게임이에요. Godot 4로 만들어요.

지금은 **첫 플레이 버전**이에요. 가게 홀, 주방, 도토리 숲 마을 세 곳이 있어요.

## 집 컴퓨터에서 실행하기

1. [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/) 표준판(Standard)을 받아요. 설치 없이 압축만 풀면 돼요.
2. 이 저장소를 받아요.
   ```
   git clone https://github.com/ryuthwjd12-ctrl/bakery-game.git
   ```
3. Godot를 열고 **가져오기(Import)** 에서 `bakery-game/project.godot` 를 골라요.
4. 처음 열 때 그림을 불러오느라 조금 걸려요. 끝나면 오른쪽 위 ▶ 버튼(F5)으로 실행해요.

## 조작

| 키 | 하는 일 |
|---|---|
| 방향키 / WASD, 또는 바닥 클릭 | 걷기 |
| E (또는 스페이스) | 문 들어가기, 가게 열기, 산딸기 따기 |
| R | 레시피북 |
| Esc | 창 닫기, 주방에서 홀로 |

## 지금 들어 있는 것

- **시작 화면**: 여자/남자 주인공 고르기, 이어하기.
- **가게 홀**: 손님(토끼·고양이·사슴·병아리)이 들어와 앉아서 메뉴 이름 대신 힌트로 주문해요. 알바생 강아지가 진열장에서 음식을 갖다주고, 손님이 떠난 자리를 쓸어요. 지저분한 자리가 많으면 가게 점수가 떨어지고 손님이 덜 와요.
- **주방**: 선반의 재료와 도구를 눌러 아래 다섯 칸에 넣고 "굽기". 순서는 상관없어요. 맞으면 오븐에 들어가서 시간이 지나면 저절로 진열장에 놓여요(타지 않아요). 틀리면 "실패"만 뜨고 재료는 사라져요. 도구는 닳지 않아요.
- **레시피북**: 처음엔 비어 있고, 조합에 성공하면 등록돼요.
- **도토리 숲 마을**: 재료 가게에서 개수를 골라 사고, 산딸기 덤불에서 하루 한 번씩 딸 수 있어요. 다른 가게는 아직 준비 중이에요.
- **시간**: 오전 9시부터 오후 9시까지, 게임 하루는 실제 12분이에요. 하루가 끝나면 자동 저장돼요.

레시피는 7가지예요. 무엇을 넣는지는 직접 찾아보세요. 정답이 궁금하면 `scripts/game_state.gd` 의 `RECIPES` 에 있어요.

## 폴더

| 폴더 | 내용 |
|---|---|
| `scripts/` | 게임 코드 (GDScript) |
| `assets/` | 게임에 쓰는 그림 (잘라낸 것) |
| `art/raw/` | 제미나이 원본 그림. Godot는 이 폴더를 무시해요 |
| `tools/slice.py` | 원본 그림을 잘라 `assets/` 를 만드는 스크립트 |
| `tools/shots.tscn`, `tools/smoke.tscn` | 개발용 화면 찍기·자동 점검 장면 |
| `docs/` | 기획서와 그림 프롬프트 |

## 그림 다시 자르기

새 그림을 `art/raw/` 에 넣고 `tools/slice.py` 의 좌표를 고친 뒤:

```
pip install pillow numpy scipy
python3 tools/slice.py
```
