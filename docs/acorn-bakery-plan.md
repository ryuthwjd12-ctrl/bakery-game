## 1. 한 줄 소개

동물 친구들이 사는 마을에서 작은 빵집을 열고, 레시피를 직접 찾아내고, 마을 밖으로 재료를 구하러 모험을 떠나는 2D 가게 운영 게임.

| 항목 | 결정 |
|---|---|
| 이름 | **도토리 베이커리 (Acorn Bakery)** · 스팀·상표 중복 확인 전 |
| 플랫폼 | 스팀(PC) 먼저. 나중에 같은 게임을 모바일로도 낼 수 있음 |
| 엔진 | Godot 4 (무료, Claude Code로 만들기 좋음) |
| 화면 | 비스듬히 내려다보는 2D (쿼터뷰). 걸어 다니는 지도는 화면 끝으로 가면 다음 장소로 넘어감 |
| 가격 | 1회 결제 약 $9.99 (회사 겸업 승인 뒤) |
| 원작과의 거리 | 어릴 때 하던 가게 게임의 "느낌"만. 이름·그림·음악·레시피 목록은 새로 만듦 |

## 2. 주인공과 친구들

- **주인공은 사람.** 시작할 때 여자 또는 남자 중 하나를 골라요. 키는 4~5등신, 귀여우면서 사람 느낌.
- 머리 모양, 모자, 앞치마, 옷을 꾸밀 수 있어요 (내 마을 옷 가게).
- **동물 친구들**은 손님, 알바생, 마을 주민이에요. 쿠키 타이머 앱의 친구들과 같은 세계관.
- **알바생(강아지)**: 홀을 맡아요. 주문 받기, 음식 전달, 청소. 머리핀이나 옷을 선물하면 바로 쓰거나 입고, 좋아하는 선물이면 일을 더 잘해요.
- 다른 마을 주민은 누르면 간단한 인사만 해요.

## 3. 가게 운영

- **홀**: 손님이 들어와 앉아 주문 → 알바생이 주문을 주방에 전달 → 내가 만들면 알바생이 가져다줌 → 손님이 먹고 돈을 냄.
- **주방은 따로 넘어가는 화면.** 위쪽 선반에 재료가 개수와 함께 크게, 그 아래 그릇·도구, 맨 아래 조합 칸.
- **만드는 법**: 그릇·재료·도구를 눌러 넣고 확인. 넣는 순서는 틀려도 됨. 오븐 메뉴는 넣어두면 시간이 지나 자동 완성(타지 않음). **미니게임 없음.**
- **레시피는 직접 찾아야 해요.** 처음엔 레시피북이 비어 있고, 조합에 성공해야 등록. 힌트는 손님 대사 정도만. 덜 친절해서 외워서 만들게 되는 게 재미.
- 틀린 조합은 "실패" 메시지만 뜨고 넣은 재료는 잃어요.
- 숨은 장식을 더하면 손님 만족도와 팁이 올라가요.
- **가게 점수 = 청결도 + 인테리어 점수.** 높을수록 손님이 많이 와요. 가게 레벨이 오르면 새 마을이 열려요.

## 4. 메뉴

- **중심은 쿠키·케이크·빵.** 음료는 세트용으로 4가지만.
- 레시피 31개: 쿠키 8, 빵 8, 케이크 6, 음료 4, 몬스터 재료로만 만드는 특별 메뉴 5.
- 그릇 가게에서 그릇을 사야 그 그릇에 담는 메뉴를 팔 수 있어요.

## 5. 마을과 지도

```
                 [벌집 꽃밭] 위험
                      |
                 [꽃잎 언덕] 북
                      |
[눈꽃 산 정상]—[눈꽃 산마을]—[도토리 숲 마을 · 내 가게]—[조개 바닷가]—[바닷가 동굴]
   위험·보스         서              가운데                   동          위험
                      |
                 [사과 과수원] 남
                      |
                 [어둠 헛간 숲] 위험
```

- 내 가게가 있는 **도토리 숲 마을이 가운데**, 동서남북에 마을 하나씩, 각 마을 바깥에 위험 지역.
- **이동은 걸어서만.** 버스 없음. 돌아올 때도 걸어서. 걷는 동안 게임 시간이 흘러서 가게를 비우는 시간이 생겨요.
- 마을 사이 길에 약한 몬스터, 위험 지역엔 센 몬스터와 희귀 재료.
- **마을마다 재료 상점**(그 마을에서만 파는 재료)과 **채집 구간**(땅에 자란 재료를 눌러서 캠, 다음 날 다시 자람).
- 내 마을에는 재료 상점, 그릇 가게, 가구점, 인테리어 상점, 옷 가게, 도구점.
- **인테리어 상점**은 마을이 열릴 때마다 그 마을 테마의 러그·그림·벽지·바닥이 들어와요.
- **M 키로 전체 지도**를 열면 내 위치가 보이고, 안 가본 곳은 흐리게, 잠긴 곳은 자물쇠.
- 재료는 상하지 않아요.
- 1.0에 다섯 곳 모두 넣어요.

## 6. 전투

- 주인공이 검(주걱 검 → 밀대 검 → 거품기 검)과 마법(오븐 불꽃, 휘핑 회오리, 아이싱 얼음)을 써요.
- 가벼운 전투: 클릭으로 휘두르기, 숫자 키로 마법. 몬스터는 귀엽게.
- 몬스터를 잡으면 **그 지역에서만 나는 재료**를 떨어뜨려요.
- 체력이 0이 되면 가게로 돌아오고 그날 모은 재료의 절반을 잃어요.
- 내가 만든 음식을 먹으면 체력·마나 회복. 가게와 모험이 이어지는 고리.
- 1.0 몬스터: 지역당 2종 + 눈꽃 산 정상 보스 1.

## 7. 그림

- **그림체 확정 (2026-10-29)**: 제미나이로 만든 주인공 시트([여자](art/hero-female-sheet.png), [남자](art/hero-male-sheet.png))가 게임 전체 기준. 얇은 갈색 선, 부드러운 파스텔, 5등신, 크림색 바탕.
- 그림은 제미나이로 만들고, 항상 주인공 시트를 참고 이미지로 같이 올려요. 배경 지우기, 잘라내기, 동작 묶음 만들기, 게임에 넣기는 Claude가 해요.
- 프롬프트와 참고 이미지에 다른 게임 이름이나 원작 스크린샷을 쓰지 않아요.
- 스팀 대표 그림은 사람 작가에게 맡기고 저작권 양도 계약을 받는 걸 추천.
- 스팀 등록할 때 AI 그림 사용을 밝혀야 해요.

## 8. 일정

| 단계 | 내용 | 기간 (추정) |
|---|---|---|
| 첫 플레이 버전 | 가게 홀 + 주방 화면 + 도토리 숲 마을, 레시피 6개, 손님 4명, 알바생, 재료 상점, 숲 채집. 그림은 임시 | 1~2주 |
| 그림 입히기 | AI로 만든 주인공·가게·주방 그림 넣기 | 그림 나오는 대로 |
| 마을 넓히기 | 마을 4곳, 위험 지역, 전투, 레시피 31개 | 2~3개월 |
| 다듬기 | 밸런스, 저장, 영어 번역, 스팀덱 확인, 데모 | 1개월 |

전체 3~5개월 정도로 봐요. 직접 플레이해보는 횟수에 따라 달라지고, 첫 버전을 만들어보면 더 정확해져요.

## 9. 회사 겸업 조건

- 개발은 **집 데스크톱, 개인 계정, 근무 시간 밖**에서만.
- 스팀 등록비 결제, 스팀 페이지 공개, 유료 판매는 **회사 서면 겸업 승인 뒤**. 모회사가 게임 회사라 게임은 앱보다 동종 분야로 볼 여지가 커요.
- 승인 전까지는 혼자/지인 테스트만.
