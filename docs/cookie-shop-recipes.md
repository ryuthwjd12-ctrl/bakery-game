# 쿠키 가게 게임 레시피 초안 (2026-10-29)

방향: 쿠키·케이크·빵 중심, 음료는 곁들임 몇 가지. 레시피는 처음에 숨겨져 있고, 주방에서 직접 조합해서 성공하면 레시피북에 등록돼요. 원작 레시피 목록은 옮기지 않고 새로 짰어요.

## 0. 주방 화면 (2026-10-29 사용자 결정)

- 주방은 홀과 **다른 화면**으로 넘어가요. 화면 위쪽 선반에 가진 재료가 개수와 함께 크게 보이고, 그 아래 줄에 그릇·도구가 있고, 맨 아래 "조합 칸"에 고른 것이 그릇 + 재료 + 재료 ... 순서로 놓여요. 다 넣으면 확인 버튼.
- 화면 구조만 참고하고 그림·배치 디자인은 새로 그려요.

## 1. 주방에서 만드는 방법 (모든 레시피 공통, 미니게임 없음)

주방에 들어가서 **그릇·재료·도구를 차례로 눌러 넣으면 끝**이에요. 손 기술이나 타이밍 미니게임은 없어요.

0. 알바생이 손님 주문을 받아 주방에 알려줘요. 다 만들면 알바생이 손님에게 전달해요.
1. 그릇(또는 틀) 고르기
2. 재료 넣기
3. 도구 쓰기 (밀대, 쿠키 틀, 짤주머니 등 필요한 것만)
4. 오븐이 필요한 메뉴는 오븐에 넣으면 굽는 시간만큼 기다렸다가 자동으로 완성 (타지 않음)
5. 장식(선택): 어울리는 장식을 더하면 만족도와 팁이 올라감. 장식은 레시피북에 안 나오고 손님 반응으로 알아냄.

- **넣는 순서는 틀려도 괜찮아요.** 들어간 그릇·재료·도구의 종류와 개수가 맞으면 성공이에요. 표에 적힌 순서는 자연스러운 순서일 뿐이에요.
- 맞지 않는 조합은 **"실패했어요" 메시지만 뜨고 넣은 재료는 사라져요.** 실패 아이템은 따로 없어요.
- 힌트는 손님 대사로만 줘요. 예) "버터 향 나는 바삭한 게 먹고 싶어요", "빨간 열매가 올라간 폭신한 거요".
- 표의 "짧게/보통/오래"는 오븐에서 기다리는 시간이에요. 오래 걸리는 메뉴는 미리 구워 진열대에 올려두는 식으로 운영 판단이 생겨요.

|---|---|---|---|

| **조개 바닷가** | 재료 상점 | 바다 소금, 레몬, 코코넛 | 수달, 해달, 오리 |

## 4. 값과 밸런스 (초안)

| 단계 | 메뉴 예 | 판매가 감 |
|---|---|---|
| 쉬움 | 버터 쿠키, 따뜻한 우유 | 낮음 |
| 보통 | 산딸기 잼 쿠키, 우유 식빵, 소금빵 | 중간 |
| 어려움 | 마카롱, 크루아상, 롤케이크 | 높음 |
| 희귀 | 눈꽃 꿀 케이크 | 아주 높음, 하루에 한두 개만 |

- 같은 메뉴만 계속 팔면 손님이 질려서 값이 조금씩 내려가요. 여러 레시피를 찾게 만드는 장치예요.
- 그릇이 없으면 그 메뉴를 못 팔아요. 그릇 가게에서 케이크 접시, 찻잔 등을 사야 새 메뉴가 열려요.
