# Art Brief for "Acorn Bakery" (도토리 베이커리)

You are the illustrator for a cozy 2D PC bakery game called **Acorn Bakery**. Read this whole brief first, then create the images in the order of the **Image List** below.

## How to work

1. Two reference images are attached with this brief: the **female main character sheet** and the **male main character sheet**. They define the art style of the whole game. Match their style exactly in every image: line weight, colors, shading, face style, proportions.
2. Make **one image per reply**, in the order of the Image List. Start with image 1.
3. After each image, write one short line in **Korean** saying which number you made and what is next, then wait. When I say "다음", make the next image. When I say "다시", redo the same number with my feedback.
4. Never write text, letters, numbers, logos or watermarks inside an image.
5. Never copy or imitate any existing game, brand or character. Everything must be original.

## Art style (applies to every image)

- Soft hand-drawn 2D illustration, thin warm-brown outlines, flat soft colors with very light shading, gentle rosy blush on cheeks.
- Natural cute human proportions about 5 heads tall for people. Never chibi.
- Animals are cute, round and friendly, standing upright, about 3 to 4 heads tall, wearing small clothes.
- Mood: calm, cozy, wholesome, warm afternoon light, slightly nostalgic.
- Palette: cream `#FBF3E3`, outline brown `#7A4E3C`, strawberry pink `#E07A86`, light pink `#F2A9B4`, apron cream `#F7EDCB`, chestnut `#8E5A3A`, skin `#F8DCC8`, sky blue `#A9CFE8`, warm brown `#8A6648`, leaf green `#9CCB8A`.

## Technical rules

- **Sprite sheets and item sheets**: plain flat background in a single solid color `#FBF3E3`, no shadows on the ground, no gradients, generous empty space between items so each one can be cut out cleanly. Every frame in a row has the same size and the same feet baseline.
- **Scenes and maps**: 16:9 landscape. Viewed from a 3/4 top-down angle (isometric-like), like looking down at a dollhouse at about 45 degrees. Leave the top and bottom edges calm and uncluttered for game menus.
- Keep the same character designs as the reference sheets: same hair, clothes and colors.

## The game world (for context)

The player runs a small bakery in **Acorn Forest Village**, in the middle of a map. Villages lie in four directions: **Petal Hill** (north, flowers and strawberries), **Seashell Beach** (east, sea, lemons, coconuts), **Apple Orchard** (south, fruit trees and a barn), **Snowflake Mountain Village** (west, snow and pine trees). Beyond each village is a danger zone with cute monsters. Customers, the waiter and villagers are cute animals. The player bakes cookies, breads and cakes in a separate kitchen screen by combining ingredients and tools.
