# 제미나이 다시 받을 그림 (2026-10-29)

첫 플레이 버전은 지금 받은 그림으로 시작할 수 있어요. 아래는 정식 게임에 넣기 전에 다시 받으면 좋은 것들이에요. 제미나이 새 대화에 `gemini-art-brief.md`, 주인공 시트 2장, 그리고 아래 중 하나를 붙여넣어요. 위에서부터 중요한 순서예요.

## 1. 걷기 동작을 잘리지 않게 (가장 중요)

지금 여자 걷기 3장은 양쪽 끝 캐릭터가 화면 밖으로 잘렸고, 남자 앞·뒤 걷기는 없어요.

```
Redo the walk cycle as a clean sprite sheet: exactly 6 frames in one row, each full body figure completely inside the image with empty space on all sides, nothing cut off at the edges, same size and same feet baseline in every frame, plain flat #FBF3E3 background. Character: [female hero / male hero] from the reference. Direction: [walking toward the viewer / walking away / walking to the right].
```

필요한 것: 여자 3방향, 남자 3방향 = 6장.

## 2. 빈 가게와 빈 주방

가구가 그림에 붙어 있으면 인테리어를 바꿀 수 없어요.

```
Same bakery room as the attached bakery hall image, same angle and style, but completely empty: only the walls, wallpaper, wooden floor, windows, the kitchen doorway and the front door. No furniture, no plants, no rug, no display case, no text.
```

```
Same kitchen screen as the attached kitchen image, same style, but the shelves are completely empty and the tool row is empty. Keep the shelves, the wooden tray with five slots and the brick oven. No items, no text.
```

## 3. 마을 지도는 한 장에 하나씩, 글자와 캐릭터 없이

지금 마을 4곳과 지도는 한 장에 모여 있어서 작고, 간판에 영어 글자가 있어요.

```
Redo [Acorn Forest Village / Seashell Beach / Apple Orchard / Snowflake Mountain Village / Petal Hill / Forest Path] as a single full 16:9 image on its own, 3/4 top-down view matching the attached bakery hall angle. Shop signs show only small pictures (a bread, a cup, a chair), never letters. No characters or animals. Wide open paths where a character can walk.
```

## 4. 몬스터 (25번, 아직 없음)

```
Make image 25 from the brief: the monster sheet, 8 cute monsters each separate with 2 idle frames, plain flat #FBF3E3 background, no text.
```

## 5. 아이콘은 섞지 말고 종류별로 한 장씩, 글자 없이

지금 아이콘 그림에 "Part 5", "Cookiuers" 같은 글자가 들어갔고, 한 줄에 빵과 가구가 섞였어요.

```
Redo image [27 / 28 / 29 / 30 / 31] from the brief on its own: one item per square in a neat grid, exactly the items listed and in that order, no titles, no labels, no text anywhere.
```

## 6. 스팀 대표 그림 (32번)

간판에 "ACORN BAKERY" 글자가 들어갔어요. 제목은 나중에 따로 넣는 게 좋아서 글자 없이 다시 받아요.

```
Redo image 32 from the brief: same scene, but the shop sign is blank with only an acorn picture, no letters anywhere.
```
